# Code of Conduct

This project follows the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful and constructive. Harassment, personal attacks, and
discriminatory language are not welcome. Maintainers may remove comments,
commits, issues, and PRs that violate this, and may block repeat offenders.

Report unacceptable behavior by opening a confidential report via GitHub
(repository → **Security** → *Report a vulnerability*, or a direct message to
the maintainer). Reports will be handled discreetly.
